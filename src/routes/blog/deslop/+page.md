# My New Website

This is a historic day. Dylansatow.com has been freed from bloated Virtual DOMs and endless boilerplate code
and has embraced the simplicity and speed of svelte.

I chose to avoid any component libraries, opting instead to write an initial svelte base manually and style it using claude code, which was
able to achieve a suprisingly nice aesthetic with Tailwind CSS.

The main tooling I used was:

- SvelteKit for the general framework
- Tailwind CSS to avoid bloated component libraries while keeping visual consistency
- mdsvex as a handy markdown renderer for the blog section
- vite for builds
- sveltejs vercel adapter for vercel deployment (chosen for simplicity)

I chose to let my recent love for TUIs shine through and added vim keybinds to make the site feel like a proper TUI. Overall,
I tried to mimic the feel of a bubbletea TUI, and am quite happy with the end result.

The followup project I'm planning is to implement an actual TUI version of the site with Go/Bubbletea as a fun exercise.
